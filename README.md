# Корпоративная ИС «Турфирма» — мобильное приложение

Курсовая работа: «Разработка мобильного приложения корпоративной информационной системы
„Туристическое агентство“». ТИСБИ, гр. П-311.

Приложение для сотрудников турагентства (менеджер и администратор):
каталог туров с поиском и фильтрами, база клиентов, оформление бронирований
с договором и предоплатой в одной транзакции, учёт платежей, справочники, журнал изменений.

## Дизайн

Палитра в стиле Discord: фиолетовые панели и кнопки (`#5865F2`, акцент `#7C5CFF`),
светло-серый фон (`#F2F3F5`), белые скруглённые карточки, полупрозрачные панели
и статус-бейджи (зелёный — подтверждено/оплачено, красный — отменено/не оплачено,
жёлтый — ожидает).

## Запуск

1. Открыть папку проекта в Android Studio (File → Open).
2. Дождаться Gradle Sync, запустить конфигурацию **app** (зелёная стрелка) на эмуляторе или телефоне.

Требования: Android Studio с AGP 9.x, JDK 17+ (встроенный JBR), SDK Platform 37 (скачается сама).

## Сборка APK

```bash
./gradlew assembleDebug
```

Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.
Его можно скинуть на телефон по USB/мессенджеру и установить, разрешив
«Установку из неизвестных источников». Debug-подписи достаточно для личного использования.

## База данных

Локальная БД Room/SQLite (файл `travel_agency.db`), создаётся при первом запуске
и наполняется контрольными данными: 10 направлений, 12 отелей, 5 туроператоров,
6 типов питания, 12 туров, 12 клиентов, 3 сотрудника, брони/договоры/платежи.

Целостность:
- внешние ключи (RESTRICT/SET NULL) + индексы;
- транзакция оформления продажи: бронь + договор + предоплата вместе (`createBookingWithDocuments`);
- триггеры: контроль квоты мест (`trg_bookings_guard_*`, `trg_bookings_after_*`),
  аудит смены статуса брони (`trg_bookings_audit`);
- суммы хранятся в копейках (Long), пароли — SHA-256.
