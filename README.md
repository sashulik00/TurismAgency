# Турфирма — мобильное приложение корпоративной ИС

Мобильное приложение для сотрудников туристического агентства. Заменяет бумажный учёт и таблицы: менеджер оформляет продажу тура за пару минут, администратор управляет каталогом и персоналом. Все данные хранятся на самом устройстве в локальной базе и работают без интернета.

Курсовая работа по дисциплине «Разработка мобильного приложения корпоративной информационной системы» (ТИСБИ, гр. П-311).

## Что можно делать в приложении

**Менеджер по туризму:**
- искать туры в каталоге — по названию, стране, городу или отелю, фильтровать по направлению;
- смотреть карточку тура: отель, категория, питание, туроператор, цена, свободные места, даты;
- вести базу клиентов: добавлять, редактировать, искать по фамилии и телефону;
- оформлять продажу: бронь + договор + предоплата 30% создаются одной операцией;
- принимать платежи (наличные, карта, перевод, СБП), видеть остаток по договору;
- расторгать договоры — бронь и договор аннулируются вместе, места возвращаются в тур.

**Администратор (дополнительно):**
- добавлять и редактировать туры, снимать их с продажи;
- управлять справочниками: туроператоры, направления, отели, типы питания;
- создавать учётные записи сотрудников;
- смотреть журнал изменений — какие брони и когда меняли статус.

**Общее:**
- вход по сотруднику и паролю (хеш SHA-256), интерфейс зависит от роли;
- настройка скрытия денежных сумм — удобно, когда рядом клиент;
- история броней прямо в карточке клиента.

## Стек разработки

| Слой | Технологии |
|---|---|
| Язык | Kotlin |
| UI | Jetpack Compose, Material 3 |
| База данных | Room (SQLite) — 11 связанных таблиц |
| Архитектура | MVVM (ViewModel + StateFlow), репозитории, однонаправленный поток данных |
| Навигация | Navigation Compose (типизированные маршруты) |
| Асинхронность | Coroutines, Flow |
| Хранение настроек | DataStore |
| Тесты | JUnit — юнит-тесты расчёта сумм и валидации форм |
| Сборка | Gradle, Android Gradle Plugin |

## База данных

Локальная SQLite-база создаётся при первом запуске и наполняется контрольными данными (12 туров, 12 клиентов, отели, направления, сотрудники). Целостность данных обеспечена:

- внешние ключи и индексы на всех связях между таблицами;
- триггеры: контроль квоты свободных мест при бронировании и автоматический аудит смены статусов;
- транзакции: оформление продажи (бронь + договор + платёж) и расторжение выполняются как единое целое.

## Как запустить

**Видео с демонстрацией:** файл `демо_приложения.mp4` в корне репозитория.

**Вариант 1 — готовый APK.** Скачать `app-debug.apk`, перекинуть на телефон (Android 8.0+), установить с разрешением «из неизвестных источников».

**Вариант 2 — из исходников.** Открыть папку проекта в Android Studio, дождаться Gradle Sync, нажать Run ▶ (эмулятор или подключённый телефон).
